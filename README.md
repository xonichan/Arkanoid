# Arkanoid

## Описание игры

**Arkanoid** — классическая аркадная игра, в которой игрок управляет платформой (ракеткой) для отбивания шарика и разрушения кирпичиков, расположенных на экране.

### Основные элементы игры:

- **Шарик** — отбивается платформой и разбивает кирпичи. Со временем ускоряется.
- **Платформа (ракетка)** — управляется с помощью мыши или клавиш со стрелками (влево/вправо)
- **Кирпичи** — расположены в сетке 3×7, при попадании шарика исчезают
- **Счетчик очков** — увеличивается при разрушении каждого кирпича
- **Жизни** — 3 жизни; теряются при пропуске шарика вниз

### Управление:
- **Мышь** — движение платформы
- **Стрелки влево/вправо** — движение платформы
- **Пробел** — поставить игру на паузу / продолжить

### Цель игры:
Разрушить все кирпичи на экране, не потеряв все жизни. При победе игра возвращает на главную страницу.

### Особенности:
- Шарик постепенно ускоряется (коэффициент ускорения: +0.001 за кадр)
- Кирпичи синего цвета с синей обводкой
- Шарик фиолетовый с тенью
- Канвас 640×480 пикселей с темно-синим фоном
- Бонусы (выпадают в 20% случаев при разбитии кирпича):
  - 🟢 **Зеленый бонус** — +1 жизнь
  - 🟣 **Фиолетовый бонус** — +1 дополнительный шарик (отлетает от текущего)

## Правила игры

### Общие правила
1. Игра начинается с одним шариком и 3 жизнями
2. Цель — разрушить все 21 кирпич на экране
3. Каждый кирпич при разрушении приносит 1 очко
4. Шарик автоматически ускоряется каждую итерацию

### Управление жизнями
- При пропуске шарика вниз теряется одна жизнь
- После потери всех 3 жизней игра заканчивается
- Бонусы позволяют получить дополнительные жизни

### Бонусы
- При разбитии кирпича с вероятностью 20% выпадает бонус
- Бонусы падают вниз — их нужно поймать шариком
- **Зеленый бонус** (+1 жизнь): поймай шариком, чтобы получить дополнительную жизнь
- **Фиолетовый бонус** (+1 шарик): поймай шариком, чтобы создать дополнительный шарик, который отлетит в противоположную сторону

### Управление игрой
- **Начать новую игру**: нажмите кнопку "New game" или перезагрузите страницу (F5)
- **Выйти на главную**: нажмите кнопку "Exit"
- **Пауза/Продолжить**: нажмите пробел (space)
- **Победа**: разбейте все кирпичи — появится надпись "YOU WIN!"
- **Поражение**: потеряйте все жизни — появится надпись "GAME OVER"
